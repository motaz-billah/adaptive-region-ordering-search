# Contributing

This repository is an experimental research prototype. Before proposing algorithmic changes:

1. Preserve a reproducible baseline and record the source revision.
2. Add correctness tests for hits, misses, duplicates, empty arrays, and distribution changes.
3. Benchmark against the same query sequence and include learning/reordering overhead.
4. Report both wins and losses; do not generalize beyond the tested data and environment.
5. Do not overwrite historical result files. Add a new dated result file with configuration and seed.

Please discuss major changes with the project team before submitting them.
